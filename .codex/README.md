# Codex workflow

Start Codex from this repository and have it read AGENTS.md first.

Recommended first task:

"Read AGENTS.md and docs/STAGE4_CODEX_TASK.md. Inspect the current repository and implement Stage 4 incrementally. First reproduce and fix any local startup/browser errors. Then integrate a real reconstruction backend behind the existing adapter. Do not vendor third-party model code or weights until its license has been verified. Add tests and keep the app runnable when GPU dependencies are unavailable."

Keep changes in focused commits or a feature branch so they are easy to review.
